## Возможности

| Функция | Описание |
| :--- | :--- |
| **Режим «Дзен» (Zen Mode)** | Полноэкранный фокус на уроке без отвлекающих рамок. Включает интерактивный **Zoom & Pan** колёсиком мыши (с защитой от ложного зума при скролле чата/эмодзи) и перемещение зажатой ЛКМ. |
| **Плавающий чат и докбар** | Компактный плавающий чат в Дзене: свободное перетаскивание за 6 точек, изменение размера по 8 сторонам, динамическое поле ввода (1–3 строки без постоянного скроллбара), сохранение положения и размеров между парами. Полная изоляция: в обычном режиме чат на 100% нативный. |
| **Умная тёмная тема слайдов** | Аппаратная GPU-инверсия (SVG `feColorMatrix`), сохраняющая акцентные цвета, графики и формулы. 4 пресета: *Maxitet*, *AMOLED (Контраст)*, *Мягкий* и *Инверсия*. |
| **Режим невидимки (Stealth)** | Маскировка присутствия через подмену Page Visibility API и фокуса вкладки. Занятие остаётся активным при переключении окон, встроен фоновый анти-AFK микропульс. |
| **Заморозка камеры** | Подмена реальной веб-камеры на виртуальный поток: зацикленная 3-секундная запись с эффектом «пинг-понг», пользовательский GIF/видео или статичный стоп-кадр. |
| **Предохранитель микрофона** | Аппаратная блокировка медиапотока от случайного включения звука на занятиях. |
| **Экспорт в PDF и снимки** | Скачивание всех слайдов занятия в единый PDF-документ (фоновая загрузка) и быстрое сохранение/копирование текущего кадра в буфер обмена. |
| **Картинка в картинке (PiP)** | Вынос видеопотока преподавателя или демонстрации экрана в отдельное плавающее окно. |

## Горячие клавиши

| Клавиша | Назначение |
| :---: | :--- |
| <kbd>Z</kbd> | Включение / выключение режима «Дзен» |
| <kbd>C</kbd> | Открыть или скрыть всплывающий чат в режиме «Дзен» |
| <kbd>Esc</kbd> | Закрыть чат и вернуть фокус |
| <kbd>+</kbd> / <kbd>-</kbd> / <kbd>0</kbd> | Приблизить / отдалить / сбросить масштаб слайда в «Дзене» |
| <kbd>D</kbd> | Включение / выключение тёмной темы слайдов |
| <kbd>Shift</kbd> + <kbd>D</kbd> | Переключение пресетов темы (*Maxitet* → *Контраст* → *Мягкий* → *Инверсия*) |
| <kbd>S</kbd> | Копирование снимка текущего слайда в буфер обмена |

> [!NOTE]
> Горячие клавиши перехватываются даже внутри iframe и плеера, но автоматически отключаются при наборе текста в поле ввода чата.

## Установка

Поддерживаются любые браузеры на базе Chromium: Google Chrome, Яндекс Браузер, Edge, Brave, Opera.

### Способ 1: Из готового релиза (Рекомендуется)

1. Скачайте архив `extension.zip` со страницы [**Релизов**](https://github.com/mqdnx/mm/releases/latest).
2. Распакуйте архив в постоянную папку на компьютере.
3. Откройте в браузере `chrome://extensions/` и включите тумблер **«Режим разработчика»** (*Developer mode*).
4. Нажмите **«Загрузить распакованное расширение»** (*Load unpacked*) и выберите распакованную папку.

### Способ 2: Из исходного кода (Git)

```bash
git clone https://github.com/mqdnx/mm.git
```
Откройте `chrome://extensions/`, включите «Режим разработчика» и выберите папку `extension`.

## Использование

1. Перейдите на урок [vision.maximumtest.ru](https://vision.maximumtest.ru).
2. Нажмите на иконку **Maxitet Master** в панели браузера для быстрой настройки.
3. Используйте горячие клавиши или боковой докбар для переключения режимов.
