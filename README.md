## Ключевые возможности

| Функция | Описание |
| :--- | :--- |
| **Режим «Дзен» (Zen Mode)** | Полноэкранный просмотр презентации без лишних панелей интерфейса. Включает плавающий боковой док управления и компактный чат по клику или клавише. |
| **Умная тёмная тема слайдов** | Аппаратная GPU-фильтрация (SVG `feColorMatrix`) без искажения фирменных оттенков графиков, акцентов и схем. 4 пресета: *Maxitet*, *Контраст (AMOLED)*, *Мягкий* и *Инверсия*. |
| **Режим невидимки (Stealth)** | Маскировка присутствия через подмену Page Visibility API и фокуса вкладки. Занятие остаётся «активным» при переключении окон, плюс встроен периодический анти-AFK микропульс. |
| **Заморозка камеры** | Подмена реальной вебки на виртуальный поток: зацикленная 3-секундная запись с эффектом «пинг-понг», пользовательский GIF/видео или статичный стоп-кадр/фотография. |
| **Предохранитель микрофона** | Аппаратная блокировка медиапотока для гарантированной защиты от случайного включения звука на лекциях. |
| **Экспорт в PDF и снимки** | Автоматический сбор всех слайдов занятия в единый PDF-документ (фоновая загрузка) и быстрое копирование текущего кадра в буфер обмена. |
| **Картинка в картинке (PiP)** | Вынос видеопотока лектора или экрана презентации в отдельное плавающее окно браузера. |

## Горячие клавиши

| Клавиша | Назначение |
| :---: | :--- |
| <kbd>Z</kbd> | Включение / выключение полноэкранного режима «Дзен» |
| <kbd>C</kbd> | Открыть или скрыть всплывающий чат в режиме «Дзен» |
| <kbd>Esc</kbd> | Быстро закрыть чат и вернуть фокус |
| <kbd>D</kbd> | Включение / выключение тёмной темы слайдов |
| <kbd>Shift</kbd> + <kbd>D</kbd> | Переключение пресетов (*Maxitet* → *Контраст* → *Мягкий* → *Инверсия*) |
| <kbd>S</kbd> | Копирование снимка текущего слайда в буфер обмена |

> [!TIP]
> Горячие клавиши перехватываются даже внутри iframe и видеоплеера, но автоматически отключаются при активном вводе текста в поле чата.

## Установка

Поддерживаются любые Chromium-браузеры: Google Chrome, Яндекс Браузер, Microsoft Edge, Brave, Opera.

### Способ 1: Из готового релиза (Рекомендуется)

1. Перейдите на страницу [**Последнего релиза**](https://github.com/mqdnx/mm/releases/latest) и скачайте архив `extension.zip` из блока **Assets**.
2. Распакуйте архив в любую постоянную папку на компьютере (например, в `Документы` или отдельную папку программ).
3. Откройте в браузере страницу расширений:
   ```text
   chrome://extensions/
   ```
4. В правом верхнем углу включите тумблер **«Режим разработчика»** (*Developer mode*).
5. Нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*) и выберите распакованную папку (где лежит `manifest.json`).

> [!IMPORTANT]
> Не удаляйте и не перемещайте папку с расширением после установки, иначе браузер потеряет к нему доступ.

---

### Способ 2: Из исходного кода (Git)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/mqdnx/mm.git
   ```
2. Откройте `chrome://extensions/` и включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и укажите папку `extension` внутри склонированного проекта.

## Использование

1. Откройте страницу урока на [vision.maximumtest.ru](https://vision.maximumtest.ru).
2. Нажмите на иконку **Maxitet Master** на панели расширений браузера для открытия панели управления.
3. Используйте горячие клавиши или переключатели в меню для активации нужных функций.
