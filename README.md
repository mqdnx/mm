  # Maxitet Master

  Многофункциональное браузерное расширение для комфортной работы на платформе М.Класс ([vision.maximumtest.ru](https://vision.maximumtest.ru)).

## Возможности

- **Режим «Дзен» (Zen Mode)** — полноэкранный просмотр презентации без лишних панелей интерфейса, боковой док управления и компактный чат по клику или клавише.
- **Умная тёмная тема слайдов** — аппаратная инверсия на GPU (SVG-фильтры) с сохранением фирменных цветов графиков, акцентов и схем. 4 пресета: *Maxitet*, *Контраст (AMOLED)*, *Мягкий* и классическая *Инверсия*.
- **Режим невидимки (Stealth)** — подмена Page Visibility API и фокуса вкладки. Платформа видит урок активным, даже если окно свернуто или перекрыто. Встроен анти-AFK микропульс.
- **Заморозка камеры и защита микрофона** — подмена видеопотока веб-камеры (зацикленная 3-секундная запись с эффектом «пинг-понг», свой GIF или статичное фото) и блокировка микрофона от случайного включения.
- **Экспорт презентаций и скриншоты** — автоматический сбор всех слайдов текущего урока в единый PDF (скачивается в фоне) и копирование кадра в буфер обмена.
- **Картинка в картинке (PiP) и отдельное окно** — вынос видео преподавателя или экрана презентации в плавающее окно.

## Горячие клавиши

Горячие клавиши работают как в английской, так и в русской раскладке:

| Клавиша | Действие |
| :--- | :--- |
| `Z` / `Я` | Включение / выключение режима «Дзен» |
| `C` / `С` | Открыть или скрыть всплывающий чат в режиме «Дзен» |
| `Esc` | Быстро закрыть чат и вернуть фокус |
| `D` / `В` | Включение / выключение тёмной темы слайдов |
| `Shift` + `D` | Переключение пресетов тёмной темы (*Maxitet* → *Контраст* → *Мягкий* → *Инверсия*) |
| `S` / `Ы` | Копирование снимка текущего слайда в буфер обмена |

> [!TIP]
> Горячие клавиши перехватываются даже внутри iframe и плеера занятия, но автоматически отключаются при вводе текста в полях чата и формах.

## Установка

1. Склонируйте репозиторий или скачайте архив с кодом:
   ```bash
   git clone https://github.com/your-username/maxitet-master.git
   ```
2. Откройте страницу расширений в Chromium-браузере (Chrome, Edge, Brave, Яндекс Браузер):
   ```text
   chrome://extensions/
   ```
3. Включите переключатель **«Режим разработчика»** (Developer mode) в правом верхнем углу.
4. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку `extension` из этого репозитория.
5. Перейдите на урок [vision.maximumtest.ru](https://vision.maximumtest.ru) — панель управления доступна по клику на иконку расширения.
